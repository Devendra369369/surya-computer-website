## Security verification
- Admin password is never stored in frontend source.
- Admin API actions require a valid server session.
- Student mock-test history/results require a valid student session.
- Emergency lock uses a separate password hash and revokes admin sessions.
- Public pages continue working during admin lock.
- View Source cannot be prevented reliably; sensitive authorization is therefore server-side.
